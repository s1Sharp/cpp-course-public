# Задача 3

Абстрактная задача на понимания тем функций, работы с потоками ввода-вывода, операторов и стандартнми типами в C++.

В текстовых файлах "matrix1.txt" и "matrix2.txt" содержатся данные о матрицах, а результат их перемножения записывается в файл "result.txt".
Каждая строка входного файла имеет следующий формат:
Первая строка — количество строк и столбцов матрицы, затем следуют элементы матрицы (числа с плавающей точкой).
> `примечание:` формат выходного файла должен совпадать с входным. Для хранения 
данных в матрице лучшим способом будет `std::vector<std::vector<double>> data;`

> Можно использовать `double** data;` но тогда необходимо заниматься ручным управлением памяти и реализовать конструктор копирования или конструктор присваивания.

> Для добавления в вектор элемента используйте метод `push_back(elem)`. Для обращения к элементу используйте индексацию через `data[i][j]`. Для изменения размера вектора используйте метод `resize(new_size)` и не забывайте что у вас вложенный вектор.

* Реализуйте класс `Matrix` на C++, который считывает матрицу из потока ввода.
    * метод `read(std::istream& in)` должен корректно считывать размеры и элементы матрицы.
* Реализуйте перемножение двух матриц с помощью перегрузки оператора.
    * метод `operator*(const Matrix& other)` должен возвращать новую матрицу как результат перемножения.
    * если размеры матриц несовместимы, сообщите об этом любым известным вам способом.
* Реализуйте запись матрицы в поток вывода.
    * метод `write(std::ostream& out)` должен записывать размеры и элементы матрицы в требуемом формате
* Основывайте решение на уже написанной части кода и допишите код, который:
    * открывает файлы "matrix1.txt" и "matrix2.txt" для чтения
    * открывает файл "result.txt" для записи
    * считывает две матрицы, перемножает их и записывает результат
