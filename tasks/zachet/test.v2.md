### 3) Приведение типов(4):

Что будет выведенно в консоль?
```cpp
#include <iostream>
#include <string>    

void print(int v)  {
    std::cout << "int:" << v << std::endl;  
}   
void print(bool v)  {
    std::cout << "bool:" << v << std::endl;
}    

void print(std::string v)  {
    std::cout << "std::string:" << v << std::endl;
}    

int main()  {      
     print(1);     
     print(true);      
     print("Hello world");  
}

```
* A) 1 true Hello world
* B) int:1 bool:1 bool:1
* C) int:1 bool:1 std::string:Hello world
* D) Ничего не выведет
